# 🎁 Interactive Gift Card Website

A custom-built interactive gift card website — made as a surprise gift 
for one of my Beelingua mentees. Plain HTML, CSS, and JavaScript. 
No frameworks. Built entirely out of intention.

---

## What It Does

- Themed visuals and animated GIFs
- Custom audio that plays as part of the experience
- Interactive reveal sequence designed to be opened on a phone at a live event

---

## Stack

| Layer         | Tech                    |
|---------------|-------------------------|
| Markup        | HTML                    |
| Styling       | CSS                     |
| Interactivity | Vanilla JavaScript      |
| Assets        | Custom GIFs, MP3s, PNGs |

No build tools. No dependencies. Just files.
